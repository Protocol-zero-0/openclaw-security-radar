# Skill Install Review Checklist

Use this before installing or recommending a skill.

## Source Trust

- Who published it?
- Is the repository active?
- Is the project clearly documented?

## Permission Surface

- What tools can the skill reach?
- Does it touch files, shell, browser, or network?
- Does it require secrets or external credentials?

## Risk Questions

- Could this skill read or expose sensitive data?
- Could it perform actions users may not notice immediately?
- Could it become dangerous when combined with another skill?

## Maintenance Questions

- Does the skill have a clear owner?
- Is it updated recently enough to trust?
- If it breaks, is recovery obvious?

## Recommendation

Mark the result as one of:

- low concern
- review carefully
- avoid for now
